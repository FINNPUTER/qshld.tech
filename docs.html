How the scan works

Most wallets sign transactions with elliptic curve cryptography, ECDSA or Ed25519. Those signatures are safe against normal computers. They are not safe against a large, fault tolerant quantum computer, because Shor's algorithm can recover a private key from its public key.

So the question is simple: can someone see your public key?

  1. Format check. We check that the address is valid for the chain you picked and detect its type.
  2. Chain lookup. We query public nodes for the address: balance, transaction count and whether it ever signed something.
  3. Exposure check. We work out if the public key is hidden behind a hash, already revealed by a past transaction, or visible by design.
  4. Result. You get a status, the raw numbers behind it and a plain explanation.

What your result means

ResultMeaning
ExposedThis address has signed at least one transaction, so its public key is on-chain for good.
Exposed by designThe address format itself contains the public key. True for every Solana wallet and for Bitcoin Taproot addresses (bc1p).
ProtectedThe address has never signed anything. Only a hash of the public key is known, and a hash cannot be reversed. The first send changes this.
No private keyA Solana address that is not on the Ed25519 curve. No private key exists, so there is nothing to recover. A program controls the funds.
Smart contractAn EVM contract address. Its safety depends on the keys of whoever controls the contract.
Program accountAn executable Solana program, not a wallet.

Exposed does not mean anyone can take your funds today. It means the key is already public and will be at risk once quantum hardware is good enough.

What to do next

Bitcoin

Keep long term funds on an address that has never sent a transaction, and do not reuse addresses. Most modern wallets create a fresh receive address for you. A SegWit address (bc1q) keeps the key hidden until its first send. Taproot does not.

Ethereum and EVM chains

EVM accounts reuse one address, so every send reveals the key. A fresh address stays hidden only until its first outgoing transaction. Keep a cold address that you only ever receive to.

Solana

There is no hash layer on Solana, so a fresh address does not help. Real protection means moving funds into a quantum resistant vault program that uses hash based signatures. These exist but are optional and still early, so check any vault carefully before you trust it with funds.

Threat index

The threat index is our own score from 0 to 100 for how close quantum hardware is to breaking the signatures crypto runs on. It is a model, not a measurement.

  • Public hardware roadmaps from the large quantum computing labs
  • Peer reviewed resource estimates for breaking 256-bit elliptic curve keys
  • Error correction progress and logical qubit demonstrations
  • Post-quantum standards from NIST and how fast chains adopt them

The chain readiness scores follow the same idea: how far each network is from letting users move to quantum safe signatures.

status is one of exposed, inherently_exposed, protected, no_private_key, contract or program. Errors come back as {"error": "..."} with a 4xx or 5xx code.

Limit: 10 requests per minute per IP. Browsers can only call it from qshld.tech, server side calls work from anywhere.

Privacy

  • No accounts, no wallet connect, no signatures.
  • We do not keep a database of scanned addresses or results.
  • Server logs keep a shortened address and the result for a short time so we can fix bugs.
  • The lookup itself goes to public blockchain nodes, like any block explorer.

FAQ

My wallet says Exposed. Am I being hacked?

No. No quantum computer today can break these keys. Exposed means the key is already public, so it will be at risk once the hardware arrives. You have time to move, and you should not wait until the last moment.

Why is every Solana wallet exposed?

On Solana the address is the public key. There is no hash in between, so the key is visible from the moment the address exists.

Does QSHIELD ever ask for my seed phrase?

Never. Anyone who asks for it is trying to steal your funds, whatever name they use.

Is QSHIELD a wallet?

No. QSHIELD scans and explains. It never holds or moves your funds.

When is Q-Day?

Nobody knows. Public estimates range from 2029 to 2035. The countdown on our site uses the earliest one, because that is the date to plan for.

QSHIELD is an informational tool and not financial advice. Results are based on public data and our own modeling. Quantum timelines are projections and can change.
